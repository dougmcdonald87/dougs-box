- Superpowers brainstorming/writing-plans: new architecture or scope; get design approval before implementation.
- Superpowers systematic-debugging: unexpected behavior; reproduce and isolate before changing code.
- Superpowers test-driven-development and verification-before-completion: scoped implementation and honest test claims.
- Superpowers requesting-code-review: before integration or acceptance.
- Prove Me Wrong: one adversarial falsifier before accepting a consequential theory or fix.
- Matt Skills Curated writing-for-agents: refine AGENTS.md or skill contracts; keep pointers concise.
- Matt Skills Curated handoff: portable, redacted next-action summary.
- Matt Skills Curated workflow-designer: recurring operational loop with explicit triggers and checkpoints.
- Matt Skills Curated git-safety-guardrails: destructive/rewrite Git operations (normally forbidden here).
- omgskills harness-creator: optional external skill for context/agent reliability. Install only a pinned revision after owner review; do not clone mutable main as an implicit dependency.
- GitHub: source-of-truth for commits, workflow runs and PRs; inspect read-only first.
- Remote Desktop Commander: filesystem/shell only on verified online device.
- Deep Research / Study: optional for genuine unresolved technical questions or learning; never substitute research for live run evidence.
