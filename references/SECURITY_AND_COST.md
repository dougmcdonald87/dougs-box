# Safety, privacy, compliance and costs
- This ZIP is distributed via a PUBLIC GitHub repository. It contains no private Desktop Commander IDs, account credentials, Tailscale client secrets, personal addresses or private handover attachments. Never commit any.
- Do not copy a token from old DevBox_Start(4).py, GitHub secrets, Restic passwords or private handovers into a prompt, GitHub branch, log or ZIP.
- Never publish public RDP. Tailscale access requires the user's own grants; do not modify tags/grants without authorization.
- Do not touch the original main workflow, D: or Lenovo backup repository while working on the pilot.
- Never create/cancel/restart GitHub Actions jobs merely to investigate a status available via the API. Read first.
- GitHub Actions jobs have platform runtime limits and terms. The intended usage must comply with GitHub's acceptable-use and service terms; do not build an indefinite personal desktop by chaining jobs to bypass limits.
- The user's zero-spend requirement is an operating constraint. Before any billable or resource-heavy job, estimate likely usage and obtain explicit approval. Do not promise zero cost based on old assumptions.
- Only claim a Windows guest restored after actual independent boot and functional checks, not after upload, hashing, workflow success, or outer-host RDP alone.
- Keep machine-specific inventory in a private local overlay, not this public kit.
